编译 / 使用说明

生成的 .mq5 是单文件、自包含的 EA，不依赖任何 JSON 文件和外部解析器。所有参数都直接硬编码到源码里。
  1. 点 "下载 .mq5" 得到源码文件
  2. 用 MetaTrader 5 自带的 MetaEditor 打开它
  3. 按 F7 编译（需要安装 MT5）
  4. 把生成的 .ex5 拖到任意图表即可运行
提示：改策略只需回到本页面修改 JSON，再下载新 .mq5、重新编译即可，无需手动改源码。

支持的指标（8 种）

  • BollingerBands - 价格突破上轨做空，跌破下轨做多
  • RSI - 跌破超卖线做多，涨过超买线做空
  • MACD - 主线穿越信号线交叉
  • MACross - 双均线交叉（金叉/死叉）
  • Stochastic - %K %D 交叉 + 阈值
  • Williams %R - 超买超卖反转
  • CCI - 商品通道指数 ±100 阈值
  • MFI - 资金流量指数（量价结合）

其它功能

  • 2 种仓位模式：固定手数 / 按账户余额风控
  • 滑动窗口频率限制（每 N 小时最多 M 单）
  • 风控过滤：点差 / 交易时段 / 最大持仓数
  • 每根 K 线只触发一次（避免重复下单）
  • 自动适配 broker 的订单填充模式（FOK / IOC / RETURN）
生成的 EA 不读 JSON ——所有参数直接硬编码进二进制。改策略 → 回到本页面 → 改 JSON → 重新下载 .mq5 → MetaEditor 编译。
