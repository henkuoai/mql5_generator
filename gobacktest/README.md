# gobacktest — Go 多品种回测器

一个用 Go 写的**多品种、多周期、支持高杠杆**的外汇/黄金/指数回测引擎。
专为验证 [Quantum Titan](../../QuantumTitan量子泰坦/) 这类**动量突破型短线策略**而建，
但引擎本身是通用的（策略通过接口插件化）。

- 纯 Go 标准库实现，**零第三方依赖**，`go build` 即用
- 多品种共享一个账户，合并时间轴逐 bar 推进（贴近真实持仓与保证金占用）
- 支持 **1:500 杠杆**下的真实保证金计算、强平、手续费、滑点、库存费
- 三种盘中路径假设（乐观/中性/保守）+ 随机模式，量化 **bar 内 SL/TP 先后顺序的不确定性**
- 输出控制台摘要、成交明细 CSV、净值曲线 CSV、自包含 HTML 报告

---

## 一、快速开始

### 1. 环境

- Go 1.21+（本机实测 1.27.1）
- Python + `MetaTrader5` 包（仅用于导出数据，`pip install MetaTrader5`）

### 2. 导出历史数据

脚本会连上**当前已登录的 MT5 终端**，把指定品种的 K 线导成 CSV：

```bash
cd scripts
python export_mt5.py --tf M5,M1
# 自定义品种/输出目录：
python export_mt5.py --symbols XAUUSD,EURUSD --tf M5 --out ../data
```

> 数据深度取决于终端本地已有的历史。若某周期为空，先在 MT5 里打开该品种对应周期的图表让它下载。

### 3. 编译并回测

```bash
go build -o bt.exe ./cmd/bt

# 黄金单品种（量子泰坦的主战场）
./bt.exe -data ./data -symbols XAUUSD -tf M5 -strategy qt-v2 -balance 10000 -leverage 500

# 四品种组合
./bt.exe -data ./data -symbols EURUSD,EURGBP,XAUUSD,US500 -tf M5 -strategy qt-v2 -risk 1

# 用 M1 数据做更精细的撮合
./bt.exe -data ./data -symbols XAUUSD -tf M1 -strategy qt-v2 -path adverse
```

### 策略接口

```go
type Strategy interface {
    Name() string
    OnBarClose(ctx *Context) []Order   // 每根基准 bar 收盘后调用
    Policy() ManagePolicy              // 持仓管理参数（跟踪/停滞/最长持仓）
}
```

`Order` 用 **止损距离**（`SLDist`/`TPDist`，价格单位）而非绝对价，
由引擎按**下一根 bar 的开盘价**换算成实际止损/止盈 —— 这是为了避免用到未收盘 bar 的数据（未来函数）。

新增策略只需 3 步：实现接口 → 在 `cmd/bt/main.go` 注册 → 跑。

## 四、回测假设（重要，请务必阅读）

回测的可靠性取决于以下假设是否贴近你的真实交易：

### 1. 价格序列是 Bid，点差施加在成交上

- **多头**：开仓吃 Ask（`Open + 点差`），平仓吃 Bid
- **空头**：开仓吃 Bid，平仓吃 Ask（`价格 + 点差`）
- 点差优先用该 bar 的 `spread` 列（MT5 导出的真实浮动点差），为空则用品种默认值

### 2. bar 内 SL/TP 先后顺序 — 用 `-path` 控制

只有 OHLC 四个价，无法知道 bar 内是先摸高点还是先摸低点。四种模型：

| 模型 | 含义 | 适用 |
|---|---|---|
| `adverse`（默认） | 先走不利方向：多头按 O→L→H→C，空头按 O→H→L→C | **保守**，同时挂 SL/TP 时先判止损 |
| `neutral` | O→H→L→C | 中性 |
| `random` | 随机决定 H/L 顺序 | 用多次重复看结果的**分布**而非单点 |

**这是本回测器最大的不确定性来源。** 对"止损 10 美元、止盈 1.5 美元"这类
止损远大于止盈的策略，`adverse` 与 `neutral` 的差异会非常显著 ——
一个 bar 内同时触及两者的概率很高，谁先谁后直接决定这笔是 +1.5 还是 −10。

建议：**同一组参数分别用 `adverse` 和 `neutral` 各跑一次，只有两者都盈利，结论才站得住。**

### 3. 信号在收盘后评估，下一根 bar 开盘成交

引擎不使用当前未收盘 bar 的最高/最低价，因此不存在未来函数。
代价是无法复刻 MT5 EA 那种"盘中 tick 级触发"的入场时机 ——
对秒级剥头皮策略，这会让回测结果的绝对数值偏离实盘。

### 4. M5 vs M1 的差异极大

实测同一策略、同一品种：

| 周期 | 交易数 | 胜率 | 盈利因子 | 最大回撤 |
|---|---|---|---|---|
| M5（8.5 个月） | 431 | 81.2% | 1.11 | 77.9% |
| M1（7 周） | 238 | 96.2% | 4.60 | 2.4% |

**同一个策略，换一个周期结论完全相反。** 这说明该策略的表现高度依赖 bar 内的
价格路径细节，bar 级回测对它而言**结论不可外推**。要评估这类策略，
必须用 MT5 的 "每个 tick 基于真实 tick" 回测，或拿真实成交记录做对照。

### 5. 保证金与强平

- 保证金 = `手数 × 合约面值 × 价格 × 计价货币汇率 ÷ 杠杆`
- 可用保证金不足时**拒绝开仓**（计入"保证金拒单"）
- 保证金水平低于 `-stopout` 时平掉浮亏最大的持仓
- 交叉盘（EURGBP）的盈亏与名义价值都以 GBP 计，用 `QuoteToUSD` 换算（默认 1.34，可在 `model/symbols.go` 改）

### 6. 未建模的部分

- **隔夜利息**：默认关闭（`SwapHour = -1`）。持仓以分钟计，影响很小
- **滑点**：默认 0，用 `-slip` 施加固定滑点。真实滑点是随机且与波动相关的
- **成交拒绝/断线/重新报价**

## 五、量子泰坦策略说明

移植自 `QuantumTitanReplica.mq5` / `_v2.mq5`。信号在 **M5 收盘**评估：

**入场（需同时满足）**
1. **突破**：收盘 bar 的高点 > 前 N 根最高 + 缓冲（多头；空头镜像）
2. **动量**：收盘价 − N 根前收盘价 ≥ 阈值（多头；空头镜像）
3. **宽幅方向 K 线**（仅 v2）：振幅 ≥ ATR 倍数，且收盘位于 top/bottom 分位
4. **M5 趋势**：收盘价 > EMA20 > EMA50
5. **H1 趋势**：收盘价 > H1 EMA20 > H1 EMA50
6. **ADX** ≥ 阈值
7. 点差 ≤ 上限、超过最小开仓间隔、未触发回撤熔断

**出场**
- 固定止损（点数）
- 动态止盈 = ATR × 倍数
- 跟踪止损（浮盈达标后按距离跟随）
- 停滞离场（浮盈达标后 N 分钟无新极值）
- 最长持仓时间
- 保证金强平 / 回测结束

**仓位**：`手数 = 风险金额 ÷ (止损距离 × 每点价值)`，风险金额 = 余额 × 风险%
（可选回撤自适应风险档，复刻原 EA 的自动风险等级）

### ⚠️ 参数单位是"金价单位"，只对黄金有意义

`VelocityMinUSD`、`TrailStartUSD`、`TrailDistUSD`、`StallMinProfitUSD` 都按
**价格单位**解释（和 MT5 版一致）。黄金的价格单位就是美元，所以 `6.0` = 6 美元。

在 EURUSD 上同样的 `6.0` 等于 **60000 点**，永远不可能触发 ——
这就是多品种回测时 EURUSD/EURGBP 完全没有交易的原因。
**量子泰坦是黄金专用策略**，跨品种请用 `-strategy ema` 或自行按品种缩放参数。

## 六、输出文件

每次运行生成三个文件（`out/{策略}_{周期}_{时间戳}_*`）：

- `*_trades.csv` — 每笔成交：进出场时间/价格、止损止盈、离场原因、MFE/MAE、盈亏
- `*_equity.csv` — 净值曲线：时间、余额、净值、占用保证金、持仓数、回撤%
- `*_report.html` — 自包含报告（内联 SVG 净值曲线 + 分品种/分月/离场原因/信号漏斗）

### 信号漏斗

策略内部统计每个过滤条件挡住了多少次信号，用于调参定位：

```
trigger   47014    ← 突破/动量条件未满足
m5_trend    624    ← 被 M5 均线排列挡住
narrow_bar  469    ← 被"宽幅K线"挡住（v2 选择性核心）
signals     431    ← 最终开仓
```

哪个环节挡得最多，就是把选择性调松/调紧的旋钮。

## 七、已知局限

1. **bar 级回测无法还原 tick 级策略**（见第四节第 4 点），结论只能做相对比较
2. 指标口径按 Wilder 标准实现，与 MT5 内置指标可能有极小的初始化差异
3. 交叉盘汇率用固定值换算，未使用实时汇率序列
4. 手续费默认按 `$3.5/手/单边`（Exness Raw 档），请按你的账户改 `model/symbols.go`
5. `-path random` 的多轮平均尚未自动化，需要手动跑多次

## 八、验证建议

1. 先用 `-strategy ema` 跑一遍，确认数据、保证金、成交逻辑正常
2. 关键参数用 `adverse` 与 `neutral` 各跑一次比对
3. 用 M1 与 M5 各跑一次，看结论是否稳健 —— **不稳健的结论不要用**
4. 与 MT5 策略测试器（真实 tick 模式）的结果交叉验证，差异大说明策略对执行细节极度敏感
