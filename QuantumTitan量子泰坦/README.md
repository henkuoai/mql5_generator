# Quantum Titan MT5 逆向复刻 EA

对 MQL5 市场产品 **Quantum Titan MT5**（作者 Bogdan Ion Puscasu，实盘信号 [2362973](https://www.mql5.com/en/signals/2362973)）的逆向复刻框架。

## 背景

基于三组证据反推原 EA 的交易逻辑：

| 证据源 | 内容 |
|---|---|
| 信号页交易历史 | 108 笔实盘平仓单（2026-03-10 ~ 2026-09-11，XAUUSD+，EUR 账户，€50k → €89k） |
| 本机 MT5 终端行情 | XAUUSD M5/H1 历史 K 线（时区对齐验证：服务器 UTC+3，108/108 单入场价落在对应 M5 K 线区间内，100% 匹配） |
| 产品页 + 信号统计 | 官方宣称：无网格、默认无马丁、每单带 SL、动态追踪、8 档自动风险、最大回撤保护 |

### 逆向分析得出的核心逻辑

1. **品种/周期**：仅 XAUUSD；tick 级驱动的动量突破秒级剥头皮（持仓中位数 2 秒，71% 在 10 秒内平仓）
2. **入场**：价格突破近期极值 + 近 5 分钟动量 ≥ $4~6 + H1/M5 趋势同向 + ADX > 20
3. **止损**：固定价距 $10（13 笔亏损中 8 笔位移恰为 -10.00 美元；2026-09 起改为 $5）
4. **止盈/离场**：动态目标 ≈ 0.3~0.4 × M5 ATR(14)（约 $1.5~3），配紧跟踪与"无新极值 N 秒即离场"
5. **仓位**：手数 = 风险金额 ÷ (止损价距 × 100oz)；风险档位约 {2, 3, 5, 10}% 余额，随回撤状态自动升降（深回撤→升档恢复，新高→降档锁利）
6. **结构约束**：同一时间基本只持一仓；无网格、无马丁、无加仓摊平

完整证据链与图表见工作区根目录的分析报告 `QuantumTitan_交易逻辑分析报告.html` 及分析脚本 `titan_csv_stats.py`、`titan_stage2.py`、`titan_stage3.py`、`titan_report.py`。

## 版本

### v1 — `QuantumTitanReplica.mq5`（初版，已弃用）

按上述逻辑实现的基础框架：突破+动量触发、H1/M5 EMA 趋势过滤、固定 SL、ATR 动态 TP、跟踪止损、停滞/超时离场、回撤自适应风险档、熔断。

**实测暴露的问题**（用户 2026-03~09 XAUUSD M5 回测：**20,026 单** vs 原 EA 108 单，过频 185 倍）：

| # | 根因 | 说明 |
|---|---|---|
| 1 | **SL 单位错误** | 默认 `InpStopLossPoints=1000`，在 3 位小数黄金（digits=3，point=0.001）上只等于 **$1** 而非 $10；同时使仓位算法的手数放大 10 倍 |
| 2 | 触发阈值过松 | 动量 $4 / 缓冲 $0.3 的条件下，90% 的 5 分钟窗口都能满足 |
| 3 | 无 K 线形态确认 | 任何 tick 满足价格条件即入场 |
| 4 | 同一根 M5 K 线内可反复入场 | 缺少每根 K 线的冷却 |
| 5 | 平仓后无冷却 | 一次脉冲内反复进出 |

> v1 保留仅供对照，请勿直接使用。

### v2 — `QuantumTitanReplica_v2.mq5`（当前推荐）

在 v1 基础上的修复与增强：

| 修复项 | v1 | v2 |
|---|---|---|
| 止损（3 位黄金） | 1000 点 = $1 ❌ | **10000 点 = $10** ✓ |
| 突破缓冲 | 30 点（$0.3） | 50 点（$0.5） |
| 动量阈值 | $4.0 | $6.0 |
| **宽幅方向 K 线形态**（新增，选择性核心） | 无 | 当前 M5 K 线 range ≥ `1.2 × ATR(14)` 且价格位于 K 线 top/bottom `30%` 分位 |
| 每 M5 K 线入场次数 | 不限 | **最多 1 次** |
| 平仓后冷却 | 无 | **60 秒** |
| 动态止盈 | 0.35 × ATR | 0.40 × ATR |
| 突破回看窗口 | 6 根（30 分钟） | 12 根（1 小时） |
| ADX 门槛 | 20 | 22 |

v2 的入场需**同时满足**：宽幅方向 K 线 → 突破近 1 小时极值+缓冲 → 5 分钟动量达标 → H1 趋势同向（价 > EMA20 > EMA50）→ M5 均线同向排列 → ADX ≥ 22。预期交易频率回落至几百单量级，再经参数微调逼近原 EA 的 108 单。

## 使用

### 环境

- 品种：XAUUSD（3 位小数报价，如 4314.587；若经纪商为 2 位报价，`InpStopLossPoints` 需 ÷10）
- 账户：RAW/ECN 低点差（策略利润中位仅 ~$2/单，点差直接吃利润）；对冲账户
- 挂载：XAUUSD 任意周期图（内部固定使用 M5 + H1 数据），需允许算法交易

### 编译

在 MetaEditor 中打开 `.mq5` 文件按 `F7` 编译。（本机在无 GUI 会话下 `MetaEditor64.exe /compile` 会挂起，无法命令行编译。）

### 回测

- 品种 XAUUSD，周期 M5，模型「每个分笔 基于真实报价」
- 建议 2026-01 ~ 2026-09，并另行覆盖 2024-2025 等不同波动环境验证稳健性

### 关键参数速查（调选择性）

| 想要 | 主旋钮 | 次旋钮 |
|---|---|---|
| 更少单 | `InpMinBarRangeATR` ↑（1.5~1.8）、`InpBarClosePct` ↓（20~25） | `InpVelocityUSD` ↑（7~8）、`InpBreakoutBuffer` ↑（80~100 点） |
| 更多单 | `InpMinBarRangeATR` ↓（0.8~1.0）、`InpBarClosePct` ↑（40） | `InpVelocityUSD` ↓（4~5） |
| 贴近 108 单 | 从 `MinBarRangeATR=1.5`、`BarClosePct=25`、`VelocityUSD=7` 起步 | 观察月度 PnL 是否复现 6/7 月脉冲式增长特征 |

### 出场参数

| 参数 | 默认 | 依据 |
|---|---|---|
| `InpStopLossPoints` | 10000（$10） | 13 笔亏损中 8 笔位移恰 -10.00 |
| `InpTP_ATRmult` | 0.40 | 盈利单位移中位 ~$2 ≈ 0.3~0.4 × M5 ATR |
| `InpTrailStartUSD / InpTrailDistUSD` | 1.2 / 0.8 | 秒级离场、紧跟踪特征 |
| `InpStallSeconds` | 30 | "无新极值即离场"的停滞退出 |
| `InpStallMaxSeconds` | 1800 | 最长持仓约束（原 EA 有 88 分钟个例，故放宽） |

### 风险档位（复刻原 EA 的回撤联动）

- 基础档 `InpRiskPercent` = 5% 余额
- 回撤 ≥ `InpDDTrigger`(8%) → 恢复档 `InpDDRecoverBoost`(9~10%)（原信号 2026-05-29 回撤 9.8% 后升档，6 月 +15k）
- 净值新高 → 降档 `InpDDDeRiskPct`(3%)（原信号 07-28 起固定 3 手）
- 回撤 ≥ `InpMaxDDHalt`(15%) → 熔断停止开新仓
